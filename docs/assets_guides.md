🎨 Guide des assets — WebApp

Ce document explique l’organisation du dossier assets/.

🗂️ Structure
`
assets/
├── logo/
├── icons/
├── backgrounds/
├── ui/
└── misc/
`

📌 Règles
- Utiliser des noms explicites
- Favoriser les formats légers (SVG, PNG optimisé)
- Classer chaque ressource dans son dossier tactique
- Garder misc/ pour les fichiers atypiques

🛠️ Outils recommandés
- pngquant pour compresser les PNG  
- svgo pour optimiser les SVG  
`
