# 🧭 Overview — WebApp

Ce document présente une vue d’ensemble du projet **WebApp**.

## 🎯 Objectif
Créer une application web simple, propre et accessible, avec une structure tactique adaptée aux projets GitHub.

## 🧩 Contenu du projet
- Page HTML minimaliste
- Style CSS léger
- Logique JavaScript simple
- Dossier `assets/` structuré
- Workflows GitHub Actions
- Documentation complète

## 🪖 Philosophie
Simplicité, efficacité, lisibilité.
