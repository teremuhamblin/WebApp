# 📚 Dossier docs/
Ce dossier contient toute la documentation liée au projet WebApp.  
Il sert de centre d'information pour les développeurs, contributeurs et utilisateurs.

---

### 🎯 Objectif
- Centraliser les guides et informations techniques  
- Documenter les choix du projet  
- Faciliter la contribution et la maintenance  
- Offrir une vision claire et tactique de l’architecture WebApp

---

### 🗂️ Structure tactique recommandée
```text
docs/
├── overview.md          → Vue d’ensemble du projet
├── architecture.md      → Structure technique et organisation des fichiers
├── assets_guide.md      → Documentation sur les ressources visuelles
├── workflows.md         → Explication des GitHub Actions
├── changelog.md         → Historique des versions
└── roadmap.md           → Plan d’évolution du projet
```

---

### 🧭 Bonnes pratiques
- Garder les fichiers courts et précis  
- Utiliser des schémas ou exemples lorsque nécessaire  
- Mettre à jour la documentation à chaque version  
- Respecter la structure tactique pour rester cohérent
