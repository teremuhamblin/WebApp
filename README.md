### Sécurité front
```text
- CSP de base (à renforcer côté serveur)
- Aucun `eval`, aucune construction dynamique de code
- Gestion des erreurs JS avec `try/catch` et logs
- Respect de `prefers-reduced-motion` pour l’accessibilité
```
